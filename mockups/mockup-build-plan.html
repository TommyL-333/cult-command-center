How it gets built

Six notes on the launcher — what each screen does, where the data comes from, and which existing code it reuses. Written for whoever picks this up: every note names the tables, routes and files it touches.

01

The controls live at the bottom

No top nav, no sidebar. Five slots, thumb-height: Home, Deals, Add, Inbox, Me. Add is the raised center key because adding your own button is the thing that makes this yours rather than ours. Everything above the dock is content the creator owns.

Tap the dock. The whole screen changes; the bar never moves.
Build
  • One <nav> pinned to the viewport, 100dvh layout so it survives mobile URL bars.
  • Views swap client-side — no route change, no reload, scroll position kept per view.
  • Badges come from unread counts on /api/creator/inbox and deals needing action.
02

Deals sit above everything

First thing on the screen after your name. A side-scrolling rail of live deals with the money stated plainly. Pink appears nowhere else in the interface — if it's pink, it's money. That rule is worth protecting as more gets added.

Build
  • Reuse the existing contracts and offers data — retainer_agreements, retainer_offers.
  • Three states only: needs you, running, waiting on brand. Creators don't need our internal statuses.
  • Amount is always the creator's take, never gross.
03

Buttons, preloaded and self-serve

Ships with Creators for Mental Health, Creators Guild of America, Social Current, Reacher and the Creator App. Those are ours — curated, endorsed, not removable. Everything after that is theirs: paste a link, name it, done. No request queue, no approval step.

Hit Add in the dock, then Edit to remove one.
Build
  • Curated tiles are a server-side config array. Personal tiles go in creator_links — mirror the inner_circle_handles route shape, it already does exactly this.
  • GET / POST / DELETE /api/creator/links, plus PATCH for order once drag lands.
  • User-supplied URLs: https only, reject javascript:, render with rel="noopener noreferrer".
  • Icons fall back to a letter mark when no favicon resolves — never a broken image.
04

Edit mode is the home-screen gesture

Tiles wobble, an X appears, tap to remove. People already know this gesture from their phone, which is the point — the whole design borrows from the OS instead of from web apps. Drag-to-reorder is the obvious next step and should be planned for, not retrofitted.

Build
  • Only personal tiles enter edit mode. Curated ones stay put — dashed border already signals which is which.
  • Store position on row one so reordering is a column update, not a migration.
  • Respect prefers-reduced-motion: no wobble, X still appears.
05

One inbox for every channel

Brand DMs, TikTok Shop messages, Reacher replies, and our own notifications in a single list, each tagged with where it came from. This is the piece that makes it infrastructure rather than another tab — the creator stops checking five places.

Build
  • Start read-only: aggregate and display. Replying in-app is phase two.
  • Normalize every source to { source, from, subject, preview, received_at, url, read_at } and keep the adapters separate so a new source is one file.
  • messaging.js already exists — extend it rather than starting a second system.
06

Me is where the survey lives

Accounts, rates, and Shape the Roster — the brand survey. It sits with the profile because it's the creator telling us who they are, and it earns its place by paying off visibly: when a brand they voted for signs, they hear about it.

Build
  • Open-text write-in before the brand list, or you only learn what they think of your list.
  • Capture intent per brand — already use it / would post free / would post if paid.
  • Join votes to follower counts via inner_circle_handles. "247 creators, 18M reach" is the number that moves a brand.
What this replaces

Two creator dashboards become one

/app/creator and /inner-circle/dashboard currently model profile, rates, brands and contracts separately. This is the merge target — the launcher is the shell, and both existing feature sets land inside it.
